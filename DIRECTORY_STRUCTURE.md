# Directory Structure Inventory

## 📂 Root Directory
Contains the primary entry points for the web application.

| File | Purpose |
|------|---------|
| `admin_*.php` | Administration Control Panel (ACP) modules. |
| `db_update.php` | Database schema update utility. |
| `delete.php` | Handles post/topic deletion. |
| `edit.php` | Post editing interface. |
| `extern.php` | RSS/Atom feed generator. |
| `header.php` | Page header logic (includes HTML `<head>`). |
| `footer.php` | Page footer logic and template rendering. |
| `help.php` | BBCode and system help page. |
| `index.php` | The main board index (list of categories/forums). |
| `install.php` | The installer script (delete after use). |
| `login.php` | User login handling. |
| `misc.php` | Miscellaneous actions (subscribe, email, report). |
| `moderate.php` | Moderation tools (move, split, etc.). |
| `post.php` | Logic for creating new topics and replies. |
| `profile.php` | User profile viewing and editing. |
| `register.php` | User registration. |
| `search.php` | Search engine interface. |
| `userlist.php` | List of registered members. |
| `viewforum.php` | Displays topics within a specific forum. |
| `viewtopic.php` | Displays posts within a specific topic. |

---

## 📂 `addons/`
Contains hook-based extensions that modify core behavior without altering core files.

| File | Purpose |
|------|---------|
| `security_for_login.php` | Enhances login security. |
| `security_for_post.php` | Enhances posting security. |
| `security_for_register.php` | Enhances registration security. |

---

## 📂 `cache/`
**Must be writable.** Stores generated PHP files to reduce database load.

*   `cache_config.php`: Global settings.
*   `cache_bans.php`: Active ban list.
*   `cache_smilies.php`: Smilies definition.
*   `cache_subforums_*.php`: Subforum tree cache (per group).

---

## 📂 `img/`
Static image assets.

*   `avatars/`: User uploaded avatars (**Writable**).
*   `smilies/`: Emoticon images.
*   `icons/`: Forum status icons.

---

## 📂 `include/`
The core library of the application.

| File | Purpose |
|------|---------|
| `common.php` | **The Bootstrap.** Loaded by every page. |
| `config.php` | Database credentials (generated by install). |
| `functions.php` | General helper functions. |
| `parser.php` | BBCode parser logic. |
| `security.php` | Security utility functions. |
| `dblayer/` | Database abstraction drivers. |
| `template/` | `.tpl` files defining the HTML structure. |

---

## 📂 `js/`
Client-side scripts.

*   `common.js`: Core UI logic.
*   `jquery-*.min.js`: jQuery library.
*   `post.js`: Textarea handling and BBCode insertion.

---

## 📂 `lang/`
Localization packs.

*   `English/`
*   `French/`
*   `Russian/`

Each directory contains `*.php` files that populate global arrays like `$lang_common`.

---

## 📂 `plugins/`
Standalone administration plugins.

*   `AP_*.php`: Admin Plugin files (e.g., `AP_Poll.php` for poll management).

---

## 📂 `style/`
Themes and visual definitions.

*   Each theme has its own folder (e.g., `Air`, `Cobalt`) containing a CSS file.
*   `imports/`: Shared CSS rules.
