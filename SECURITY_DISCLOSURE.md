# Security Disclosure Policy

## 🚨 Reporting Vulnerabilities

If you discover a security vulnerability in this FluxBB fork, please report it responsibly.

### How to Report
Please **do not** report security vulnerabilities through public GitHub issues. Instead, contact the maintainers directly via email.

*   **Email:** [Insert Maintainer Email Here]
*   **Subject:** Security Vulnerability: [Brief Description]

### What to Include
1.  **Vulnerability Type:** (e.g., SQL Injection, XSS, CSRF).
2.  **Affected Version:** The version number found in `include/common.php` (e.g., 1.5.11).
3.  **Reproduction Steps:** Detailed steps to reproduce the issue.
4.  **Proof of Concept:** A snippet of code or URL demonstrating the vulnerability.

### Response Timeline
1.  **Acknowledgment:** We aim to acknowledge reports within 48 hours.
2.  **Assessment:** We will validate the issue and determine its severity.
3.  **Fix:** A patch will be developed and released.
4.  **Disclosure:** Once patched, we will publicly disclose the vulnerability in the changelog.
