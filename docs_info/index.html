1. Project Summary

This project involves enhancing and modernizing FluxBB, a lightweight PHP-based forum software, by implementing critical security improvements, performance optimizations, and modern features. The project builds upon the Visman fork of FluxBB, which is an open-source GPL v2 licensed community forum platform.

2. Project Objectives

2.1 Primary Objectives

  • Security Enhancement: Implement modern password hashing (Argon2/bcrypt) to replace insecure SHA-1 hashing currently used in the system.
  • Two-Factor Authentication: Add TOTP-based 2FA using Google Authenticator protocol with QR code generation and backup codes system.
  • Brute Force Protection: Implement rate limiting for login attempts with progressive delays and IP-based blocking to prevent credential stuffing attacks.
  • SQL Injection Prevention: Conduct comprehensive security audit and convert all database queries to use prepared statements.
  • Content Security Policy: Add modern security headers including CSP with nonce-based inline script protection.

2.2 Secondary Objectives

  • Database query optimization and indexing improvements
  • Implementation of Redis caching for performance enhancement
  • Development of comprehensive unit testing framework (PHPUnit)
  • Setup of CI/CD pipeline using GitHub Actions
  • Creation of detailed security audit documentation
